‹ Poêle

WiFi

    Le module sera joignable sur http://nom.local

    MQTT / Home Assistant

    Le poêle apparaît automatiquement dans Home Assistant (intégration MQTT).

    Poêle

    Décimal ou hexadécimal (ex. 1193046 ou 0x123456). Par défaut, un identifiant propre au module : appairez le poêle avec (voir la documentation). Si vous changez cette valeur, refaites l'appairage.

    Renvoi périodique : l'état est renvoyé sans bip, comme le fait la télécommande d'origine (300 s). 0 = désactivé. Il écrase les réglages faits avec la télécommande d'origine : retirez-en les piles. Ventilateur 2 : 7 = absent (valeur de la télécommande d'origine).

    Radio

    Si le poêle ne réagit pas, essayez l'autre modèle : avec le mauvais réglage, le module n'émet presque rien.

    Bande 868,7–869,2 MHz : 14 dBm (25 mW) maximum autorisé.

    Sécurité

    Protège aussi la mise à jour du firmware (web et OTA).

    Maintenance

    Mettre à jour le firmware

    Appui long (8 s) sur le bouton du module : efface le WiFi et ouvre le point d'accès de configuration.
